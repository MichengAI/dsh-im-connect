# 技术架构基线

更新时间：2026-08-18 17:56（Asia/Shanghai）

当前生效的硬约束。细节以 [总体架构](../03-技术架构/01-总体架构.md) 为准。

1. 形态必须是 DSH Cordis bundle 插件，TypeScript ESM。
2. Agent 只对接本机 DSH，使用 `ctx.agents` / `followup` / `session/event`，禁止 HTTP 平行会话。
3. 一个 IM 聊天对应一个id 以 `im:` 开头的 DSH agent。网页任务与 IM 频道分列，禁止混进「任务」列表。模型和 preset 跟随当前 profile。
4. 渠道不得创建会话、不得解析产品命令；引擎不得写死平台名。
5. 管理接口默认仅本机回环；Secret 只进 `ctx.credentials`，禁止回传浏览器。
6. 授权策略：群聊不用绑定，只需 @。私聊默认拒绝：`handleInbound()` 在命令、工具审批和注入之前校验 `msg.userId`；微信 / 飞书 / Lark / QQ 扫码用户自动入库，钉钉 / 企微扫码接口不返回用户身份，扫码者和其他私聊用户需在设置页批准。缺 `userId` 的私聊拒绝。工具审批只接受私聊白名单用户。不恢复 `allowAllUsers` 或钉钉开放模式。
7. 微信只使用腾讯官方 iLink。
8. 设置入口名称固定为 **IM助理**；设置页按视觉稿还原。
9. dsh-im / dsh-im-gateway / cc-connect 只作源码参考，运行时不依赖它们。
10. 工作区左侧「任务 / 频道」由当前侧栏主人绘制；本插件只注册 `sidebar.channels`，禁止 `inject('sidebar')` 与 code-ui 抢栏。
11. Windows 开发与脚本遵循仓库 `AGENTS.md`：PowerShell、UTF-8。

## 凭据引用

`ctx.credentials` 的 ref 必须匹配 `/^[A-Za-z_][A-Za-z0-9_]*$/`。本插件统一写成 `im_connect_{渠道}_{字段}`，例如 `im_connect_wecom_secret`。禁止使用斜杠或连字符。

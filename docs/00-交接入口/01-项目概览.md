# 项目概览

更新时间：2026-09-02 10:45（Asia/Shanghai）

## 定位

`dsh-im-connect` 是 DeepSeek Harness 的 **IM助理**。用户在微信、企业微信、钉钉、飞书、QQ、Telegram 里驱动本机 DSH agent，会话与 Web 分列，工具批准可以在聊天里完成。

使用步骤见 [使用说明](../02-产品与业务/04-使用说明.md)。对外介绍见仓库 [README.md](../../README.md)。

## 当前阶段

多账号能力已发布至 0.1.30。Issue #8 的工作区切换、扫码保存时序及残余并发保护已完成本地验证，待纳入下一次发布；仍待本机真实扫码与 QQ 真机手测。

## 核心能力

- 设置入口：IM助理
- 统一引擎：会话路由、斜杠命令、远程审批
- 已接渠道：钉钉、飞书、Lark、微信、企业微信、QQ、Telegram
- 每个账号独立保存工作区、模型、权限和私聊准入策略
- 工作区「任务 / 频道」分列
- 进程内对接 DSH，不另开 HTTP 会话

## 稳定边界

- 只做 DSH bundle 插件
- 微信只走官方 iLink
- 引擎不感知具体平台名
- 工作区变化必须丢弃该账号旧会话映射；Windows 忽略路径大小写，大小写敏感系统保留路径大小写语义
- 群聊不用绑定只需 @；私聊仅微信 / 飞书 / Lark / QQ 扫码用户免批，钉钉 / 企微扫码者和其他人要设置页批准；工具审批仅私聊

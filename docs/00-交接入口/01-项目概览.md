# 项目概览

更新时间：2026-08-16 21:10（Asia/Shanghai）

## 定位

`dsh-im-connect` 是 DeepSeek Harness 的 **IM助理**。用户在微信、企业微信、钉钉、飞书、Telegram 里驱动本机 DSH agent，会话与 Web 共用，工具批准可以在聊天里完成。

## 当前阶段

一期引擎、六个渠道和扫码/手动绑定弹窗已落地，待本机真实扫码手测。

## 核心能力（目标）

- 设置入口：IM助理；页面按「IM 频道」视觉稿还原
- 统一引擎：会话路由、斜杠命令、白名单、远程审批
- 一期五个渠道可用
- 进程内对接 DSH，不另开 HTTP 会话

## 稳定边界

- 只做 DSH bundle 插件
- 一期不做 20+ 骨架渠道
- 微信只走官方 iLink
- 引擎不感知具体平台名

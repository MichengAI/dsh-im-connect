## 目标与业务边界

按千问办公配置弹窗，补齐一期渠道的扫码 / 手动绑定。不把网页任务和 IM 频道混在一起。不做 `/bind`。

## 验收标准

1. `npm test` 通过
2. 未连接卡片点「配置」打开弹窗
3. 微信 / 飞书 / Lark 只有二维码
4. 企微 / 钉钉有快捷绑定和手动配置
5. 钉钉可选择配对模式或开放模式
6. 扫码成功后卡片变为已连接

# I018 会话日志导出

状态：进行中

负责人：Codex（实现）、维护者（实机验证）

优先级：P2

更新时间：2026-09-11 02:00（Asia/Shanghai）

## 目标与边界

在已支持文件回传的全部渠道接通 `/export`，导出当前绑定会话的 Chat ZIP 日志。不接受路径、其他会话 ID 或子会话选项。保持私聊准入及命令权限，不新增配置和生产依赖。

## 实现与已完成事项

- 通过宿主 `connection.createSharedFetchHandler('/api')` 分发固定 `/api/session.export` 路由，复用已安装 Chat 导出插件、持久化刷新、日志和附件打包规则。内部 URL 只用于路由匹配，无网络请求。
- 使用当前绑定会话，固定 `includeDescendants=false`；发送前再次核对绑定。
- 流式读取 ZIP，累计上限 32 MiB，总操作超时 120 秒；父信号中断时停止等待并取消读取。渠道限制仍生效。
- 全部复用渠道 `sendFile`；发送成功后才返回完成文案。缺失服务、路由、读取或发送失败提供网页下载入口；超限明确提示。中英文同步。
- 更新中英文 README，移除旧的网页专属命令文案。

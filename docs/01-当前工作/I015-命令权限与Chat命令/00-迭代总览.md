## 新建与换绑统一修复

普通消息首次创建、`/new`、`/clear`、`/workspace` 和归档后的自动轮换统一走 Router，使用账号模型、推理、Agent 与权限预设；工作区选择保存在会话索引 `cwd`，后续轮换和历史挂载使用该目录。`/session` 接续与 `/fork` 继续保留宿主原会话配置，并保存工作区归属；旧接续记录通过宿主工作区或会话列表解析目录，无法确定时提示选择，不擅自回到账号默认目录。

新建、挂载、取消或索引写入失败时保留旧绑定与句柄；索引写入失败回滚内存状态。恢复失败只有在可靠确认日志缺失时才轮换。新日志如果已由 Host 创建，不直接删除宿主日志；失败时卸载句柄并保留原当前会话。重新接续历史不生成重复索引，也不覆盖手动名称。

插件前端按渠道索引兼容普通 Host ID，更新任务过滤、打开历史、标签匹配和过滤缓存；后台刷新归属，失败保留已有结果。未修改 dsh-codex-ui 或归档插件；其他插件自有列表的分类实现不属于本次前端改动。

## 轮换后网页历史无法打开

用户复现：网页保持打开，IM 执行 `/new` 或 `/clear` 后旧会话无法点击，刷新恢复。日志与索引仍在。根因是 Router 轮换调用旧句柄 dispose，真实 Host 将 session/disposed 转成 api-session/removed；网页 SessionManager 从列表移除旧 ID，随后 select 抛 unknown session。

本次轮换成功后将旧绑定移入 historical，保留 Host 句柄和网页列表资格；停用渠道或插件重载时沿用 disposeChannelNow 统一释放。这样会保留本轮运行期间历史 Agent 的内存，不能重新通过逐次 dispose 降低占用，否则会再次触发网页移除语义。未修改归档插件或 dsh-codex-ui。

验证：新增失败回归复现 unknown session，修改后 461 项通过，0 失败、0 跳过。网页契约测试执行宿主真实 select 源码，并模拟创建/移除事件，不等同于真实浏览器点击验收；另验证连续轮换、打开历史不换绑、停用完整释放且不重复释放。真实网页和手机联合验证待用户复测。本次补修纳入上述 fix 提交；未推送、未发布。

# 卡片交互补齐

状态：进行中

目标：命令、卡片和文字回复使用相同的执行入口，用户能直接选择、看到处理反馈，并知道下一步去哪里。

按依赖顺序实施，每项独立提交：

1. 原卡片收口：有效选择后移除按钮，显示已选择；执行结果仍由后续回复准确说明。更新失败不重发、不重试操作。
2. 列表直接选择：支持按钮的渠道发送 `/sessions`、`/workspaces`、`/models` 即进入分页选择，文字渠道保留完整命令。
3. 状态操作：根据已读取的运行、目标和队列状态提供有效操作；未知状态只提供查询入口。
4. 降级诊断：区分容量、能力和发送失败，保留脱敏日志；已发送卡片更新失败不得另发副本。
5. 钉钉操作卡片：核对模板和 Stream 回调契约，不能以链接按钮或普通 AI 卡片冒充可执行命令按钮。

所有项目保持准入、命令权限、操作者、会话绑定和一次消费校验。原生展示、回调权限和手机排版需要真实账号验收，不以模拟 API 测试替代。

## 已完成

- 降级诊断：记录渠道、原因、按钮数和字符数，不记录消息正文、令牌或原始平台错误。能力缺失、容量超限和明确拒绝可完整回退；真实适配器网络发送结果未知时保留按钮状态，仅提示确认，不重发卡片正文。更新失败只记日志，不再次发送。完整测试 624 项：601 通过、0 失败、23 项契约环境未配置而跳过。关联提交：本次 `fix: distinguish rejected and uncertain card delivery`。

- 状态操作：运行时显示停止，已注册目标命令且目标活跃时显示暂停、暂停或受阻时显示恢复，有排队消息才显示队列。未知状态只提供查询；文字与按钮使用同一动作列表。构建通过，命令测试 50 项：49 通过、0 失败、1 跳过。关联提交：本次 `feat: tailor status actions to current session state`。

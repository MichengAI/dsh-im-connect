# 侧栏页签兼容

更新时间：2026-08-16 22:40（Asia/Shanghai）

工作区要同时支持：

- **只装本插件**（官方 DSH 侧栏）
- **本插件 + dsh-codex-ui**（dsh-codex-ui 整栏替换官方 sidebar）

页签交互仍对标千问办公，见 [工作区频道侧栏](../02-产品与业务/03-工作区频道侧栏.md)。会话规则见 [会话管理](./03-会话管理.md)。

## 1. 现状

| 环境 | 谁在画左侧栏 | 会话树在哪 |
|---|---|---|
| 仅 DSH | 官方 `sidebar` | 官方 `sidebar.workspaces` |
| 装了 dsh-codex-ui | dsh-codex-ui **整栏替换** `sidebar` | dsh-codex-ui 再注册 `sidebar.workspaces`（`CodexWorkspaceBrowser`） |

dsh-codex-ui 源码写明：替换官方 sidebar，不改 DSH 源码。它已经用 `session.origin !== 'subagent'` 把子 agent 会话从树里滤掉。

因此本插件 **禁止再 `inject('sidebar')`**。谁后加载谁赢，和 dsh-codex-ui 会互抢整栏。

## 2. 分工

本插件只做两件事：

1. 创建 IM 会话时打上 `im:` 前缀的 sessionId
2. 注册一个新槽 **`sidebar.channels`**：按渠道分组的频道列表

页签「任务 / 频道」由**当前侧栏主人**来画，不要两个插件各画一套 TAB。

| 角色 | 负责 |
|---|---|
| 侧栏主人（官方 或 dsh-codex-ui） | 画 TAB；任务页渲染 `sidebar.workspaces`；频道页渲染 `sidebar.channels` |
| 本插件 | 只填 `sidebar.channels`；保证 IM 会话 id 带 `im:` 前缀 |
| 任务树 | 过滤 `origin === "im"`，和过滤 `subagent` 同一规则 |

没有注册 `sidebar.channels` 时，侧栏主人不显示 TAB，行为和现在一样。

## 3. 两种宿主怎么接

### 只装本插件

本插件在探测到 **没有 dsh-codex-ui 占用 sidebar** 时，给官方 `WorkspaceBrowser` 外面套一层薄壳，**不换掉原生任务树**：

```
[ 任务 | 频道 ]
----------------
任务：官方 WorkspaceBrowser（搜索、工作区、未分组、原生菜单都还在）
频道：sidebar.channels
```

实现上是改官方条目的 `component`，官方 inject / store / 菜单完整保留。任务页的 `useSessions` 会滤掉 `im:`，所以「未分组」里不会出现 IM 会话。包裹失败时才退回自绘列表。

### 和 dsh-codex-ui 一起用

本插件 **不碰** `sidebar`、**不碰** `sidebar.workspaces`。

dsh-codex-ui 改一处即可（`CodexSidebar` 的工作区区域）：

1. 若 `sidebar.channels` 有内容，在 `dcu-workspaces` 顶部画「任务 / 频道」
2. 任务：继续 `renderSlot('sidebar.workspaces')`，即现在的项目树
3. 频道：`renderSlot('sidebar.channels')`
4. `visibleSessionIds` 增加：`session.origin !== 'im'`

本插件这边零分支：照样只注册 `sidebar.channels`。

## 4. 探测规则

本插件 **不依赖** dsh-codex-ui。没装它时，原生侧栏必须自己画出「任务 / 频道」。

探测只看 **谁真正占用了 `sidebar` 槽**（`entriesOfSlot('sidebar')`），不看插件注册表：

- 占用者名字 / locale 含 `dsh-codex-ui` / `michengai-codex-ui` / `michengai.codexUi` → 组合模式，只填 `sidebar.channels`
- 否则 → 独立模式，包裹官方 `WorkspaceBrowser`，套上本插件的「任务 / 频道」

不要再注册一个更低 priority 去盖住官方树，那会丢掉原生搜索、工作区和会话菜单。

探测失败时默认独立模式套壳。`sidebar` 主人变化时重新同步：dsh-codex-ui 后来接管了，就卸掉本插件的 workspaces 套壳，避免双页签。底线仍是「本插件不 inject sidebar」。

## 5. 页签状态

- 选中哪个 TAB 记在 `localStorage` 键 `dsh-im-connect.sidebar-tab`，刷新保持
- 打开一条 IM 会话时自动切到「频道」
- 新建网页任务时自动切到「任务」
- 折叠侧栏时不画 TAB，避免和 dsh-codex-ui 窄栏图标打架

## 6. 不做什么

- 不复制一份 dsh-codex-ui 侧栏
- 不在设置页里冒充工作区会话列表
- 不为了分列再去改 DSH 核心
- 不把 TAB 做到 `settings.section` 里凑合

## 7. 落地顺序

1. I002：本插件注册空的 `sidebar.channels`，会话 id 带 `im:` 前缀
2. 独立模式：官方树套 TAB 壳 + 任务列表过滤
3. dsh-codex-ui：加 TAB 和 `origin !== 'im'` 过滤（小改，不改会话数据）

## 目标与业务边界

修复 I010 复审确认的残余风险：扫码保存过程中前端可误取消、大小写敏感文件系统误判工作区路径、会话重置与入站创建并发，以及会话句柄卸载无限等待。只调整前端绑定状态、账号重载条件和会话路由，不修改渠道协议、凭据格式或已发布版本。

## 任务清单

- [x] 保存中禁止关闭弹窗、Escape、遮罩退出和切换绑定页签
- [x] Windows 以外的系统保留工作区路径大小写语义
- [x] 仅名称或私聊策略变化时不重载会话
- [x] 同账号会话创建、轮换、卸载和重置串行执行
- [x] 单个会话句柄卸载设置 10 秒上限并解除本地引用
- [x] 补齐聚焦回归和完整回归

## 阻塞事项

无。

## 验收标准

- `saving` 状态期间不能关闭或取消二维码绑定流程
- Linux 等大小写敏感系统中 `/srv/Repo` 与 `/srv/repo` 必须触发会话重置
- 会话重置期间的入站消息必须等待旧映射清理后创建新会话
- 卡死的会话卸载不得无限阻塞账号设置保存
- 全量测试全部通过

## 已完成内容

扫码弹窗在保存阶段锁定关闭与页签操作；账号配置仅在工作区、模型或权限变化时重载。会话路由复用按账号串行队列，并把句柄卸载限制为 10 秒。工作区路径比较按运行平台区分大小写语义。

## 核心覆盖

- 多账号隔离、开启前命名、同渠道重名、默认关闭、改名和重启后的稳定目标 ID。
- 停用后拒绝、接收关闭仍可投递、重连和重新绑定不绕过设置、删除目标、无效路由和账号原型属性。
- 按平台限制及 UTF-8 字节分片，拼接保留原文；部分成功、结果未知、取消剩余分片、脱敏错误与不自动重试。
- 七渠道请求参数和业务回执，QQ 不带回复 ID、钉钉不依赖 Webhook、企微不消费待回复帧、微信恢复上下文仍受平台限制。
- 工具与 Skill 注册/卸载，拒绝 IM 会话、子 Agent 和缺少 Agent 的调用；本机 Chat 和独立任务可调用。
- 回环 HTTP、Host 校验、写请求标记、真实 HTTP 请求分发与共享服务。

真实 Host 的 Skill 发现和 Chat 调用、七平台真实消息回执及调度方白名单联调由维护者后续验证。自动化调用契约见[主动投递接口](../../../03-技术架构/05-主动投递接口.md)。微信不承诺无上下文、固定窗口或固定额度发送。

# 设置页交互

更新时间：2026-08-16 17:08（Asia/Shanghai）

视觉稿：[01-设置页-IM频道.png](../06-设计资源/01-设置页-IM频道.png)

## 入口

- 设置里的插件页签名称：**IM助理**
- 打开后是独立设置页，不是塞在「插件」列表里的一行开关

## 页面结构（按截图 1:1）

1. 顶部装饰：左右两条提示气泡 + 中间两个头像（吉祥物 / 用户）。第一期可先用静态装饰，不接真实对话。
2. 主标题：**IM 频道**
3. 副标题两行：
   - 配置 IM 频道，让本机助手接收来自钉钉、飞书等平台的消息。
   - 频道配置信息仅存储在本地，不会上传到云端。
4. 渠道卡片纵向列表，卡片之间留缝，深色圆角描边。

截图原文是「让千问办公接收」。本产品文案改成「本机助手」，**不要出现「千问办公」**。其余层级、对齐、按钮形态按截图还原。

## 卡片两种状态

### 未连接

- 左：平台图标
- 中：平台名 + 一行说明「通过 {平台} 机器人接收并回复用户消息」
- 右：白色描边按钮 **配置**

点击「配置」打开该渠道的接入流程（扫码或填凭据），不要跳到别的设置分类。

### 已连接

- 平台名右侧绿色标签 **已连接**
- 右侧不再显示「配置」，改为：
  - `...` 更多菜单（断开、重新接入、查看状态）
  - 绿色开关，打开=接收消息，关闭=暂停接收但保留凭据

截图中微信、企业微信即为此态。

## 一期渠道顺序

按截图顺序排，并补上 Telegram：

1. 钉钉
2. 飞书
3. Lark（飞书国际版，同一适配器、不同域名，单独一张卡）
4. 微信
5. 企业微信
6. Telegram

Lark 与飞书在界面上是两张卡，实现上共用飞书适配器。

## 不在第一期做的界面

- 截图顶部那两条英文提示气泡的真实对话能力
- 渠道内的复杂统计看板
- 把 20+ 渠道塞进同一列表

## 配置弹窗

点击卡片「配置」或已连接菜单「重新接入」打开居中弹窗，不再在卡片内展开表单。

| 渠道 | 绑定方式 |
|---|---|
| 微信 | 仅二维码，可重新生成 |
| 飞书 | 仅扫码自动创建机器人，可刷新二维码 |
| Lark | 仅扫码配对，同飞书国际版域名 |
| 企业微信 | 快捷绑定（推荐）扫码，或手动填 Bot ID / Secret |
| 钉钉 | 扫码或手动。手动字段为 Client ID（原 AppKey）、Client Secret（原 AppSecret）；准入为配对模式 / 开放模式 |
| Telegram | 仅手动填 Bot Token |

配对模式：未批准用户不能驱动助手。开放模式：该钉钉渠道默认放行。

扫码成功后由本机保存凭据并启动渠道，弹窗关闭，卡片变为已连接。

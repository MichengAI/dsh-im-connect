# 工作区频道侧栏

对标：千问办公工作区侧栏。

视觉稿：[02-工作区-频道侧栏.png](../06-设计资源/02-工作区-频道侧栏.png)

## 要解决什么

工作区左侧必须能分清两类东西：

- **任务**：网页里开的会话
- **频道**：IM 里来的会话

不能混在一个列表里。设置页（IM助理 / IM 频道卡片）只负责连机器人；连上之后产生的聊天，出现在这里。

## 布局（按截图）

1. 左栏顶部两个页签：**任务** | **频道**。选中项下方一条高亮下划线。
2. 「频道」下按渠道分组，分组可折叠。截图是「企业微信」展开。
3. 组内每一行是一条 IM 会话。截图里是企微会话 ID；有备注或群名时优先显示名称，ID 作兜底。
4. 底部仍是当前账号和套餐信息，不属于本插件改动范围。

一期分组顺序与设置页一致：钉钉、飞书、Lark、微信、企业微信、Telegram。没有会话的渠道不占一组，或灰显折叠，实现时选更干净的一种，不要空组堆一屏。

## 交互

- 点页签「任务」：DSH 原会话列表，不含任何 `im:` 前缀会话。
- 点页签「频道」：只渲染本插件登记的 IM 会话。
- 点某一行：在右侧打开这条 IM 会话的记录（可看历史、可在网页里接着看，但不变成任务）。
- IM 里 `/new` 后，这一行换新 session，标题可先保持，时间更新。
- 机器人断开后，该渠道分组仍可看历史，但不再接收；具体文案实现时再定。

## 和设置页的分工

| 页面 | 管什么 |
|---|---|
| 设置 → IM助理 | 连不连钉钉/微信等 |
| 工作区 → 频道 | 已经聊起来的那些会话 |

## 和 code-ui 一起用

本插件不替换整栏。TAB 由当前侧栏主人画，本插件只提供「频道」列表槽。细则见 [侧栏页签兼容](../03-技术架构/04-侧栏页签兼容.md)。

## 实现约束

DSH 核心若没有现成的「任务/频道」页签槽位，由本插件在会话侧栏注入。  
若核心任务列表做不到按 meta 过滤，走 [会话管理](../03-技术架构/03-会话管理.md) 里的独立工作区退路，保证任务页看起来仍然干净。

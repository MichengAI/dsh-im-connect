> DSH IM Connect — это плагин для DeepSeek Harness (DSH), поддерживаемый сообществом, и не является официальным продуктом DeepSeek AI.

## Краткий обзор возможностей

Даже находясь вдали от компьютера, вы можете ставить задачи локальному агенту DSH через привычный мессенджер, просматривать ответы, отвечать на уточняющие вопросы и одобрять использование инструментов прямо в диалоге.

- **Поддержка популярных мессенджеров**: DingTalk, Feishu, Lark, WeChat, WeCom, QQ, Telegram, Discord и Slack.
- **Раздельная настройка учетных записей**: Возможность подключить несколько аккаунтов одного сервиса с индивидуальным выбором рабочей области, модели, уровня рассуждений, прав доступа и режима отправки.
- **Удобное управление со смартфона**: Отправляйте инструкции, читайте ответы и выбирайте варианты в опросах. Одобренные пользователи могут подтверждать выполнение команд прямо в личном чате.
- **Изолированные сессии**: Каждый чат мессенджера привязан к отдельной сессии, доступной для просмотра во вкладке «Каналы» веб-интерфейса.
- **Быстрое подключение по QR-коду или токену**: Настройка в меню «Настройки → IM-ассистент» с полным контролем приема сообщений.
- **Гибкий контроль доступа**: Групповые чаты реагируют на @упоминания; личные сообщения обрабатываются согласно политике безопасности.

## Кто может управлять ассистентом?

Входящие сообщения проходят проверку отправителя перед выполнением команд или согласованием инструментов.

| Сценарий | Поведение |
|---|---|
| Группа без @упоминания бота | Игнорируется; ответы или запросы на подтверждение не генерируются |
| Группа с прямым @упоминанием бота | Привязка не требуется: любой участник группы может отправить задачу |
| Личное сообщение от отсканировавшего QR | Пользователи WeChat, Feishu, Lark и QQ после сканирования QR-кода автоматически добавляются в белый список |
| Личное сообщение от остальных пользователей | Попадает в список ожидания в настройках до подтверждения администратором |
| ЛС после привязки по QR без передачи личности | Быстрое подключение DingTalk и WeCom возвращает только данные бота; требуется одобрение в настройках |
| ЛС при ручном вводе токенов | Telegram, Discord, Slack, а также ручные подключения DingTalk, WeCom и QQ требуют одобрения каждого пользователя |
| ЛС без идентификатора (userId) | Отклоняется |
| Одобрение вызова инструментов | Отправьте ответ `Одобрить` или `Отклонить` (`Approve` / `Deny`) в чате сессии. При отсутствии ответа в течение 5 минут действие безопасно отменяется |
| Интерактивный выбор вариантов | Отправьте номер варианта или текст ответа. В группах ответ принимается только от инициатора задачи |

## Работа с изображениями и файлами

Отправляйте скриншоты, фотографии или документы (PDF, код, текст) прямо в диалог. Зрительная модель DSH обработает их согласно вашему запросу. Сгенерированные файлы (ZIP-архивы, отчеты, изображения) возвращаются в чат в виде вложений.

## Быстрое меню действий

Введите команду `/menu` в чате для вызова интерактивных кнопок переключения сессий, создания новых задач или смены модели.

## Настройка плагина

Доступна в панели управления: **Плагины → @michengai/dsh-im-connect**:

### 1. Расположение ярлыка (`location`)
- **По умолчанию**: Только в настройках (`settings`)
- **Варианты**: `both` (боковая панель и настройки), `sidebar` (только боковая панель) или `settings` (только общее меню настроек).

### 2. Отображение сессий IM в дереве задач (`taskTreeSessions`)
- **По умолчанию**: Отключено (`false`)
- **Назначение**: Скрывает диалоги мессенджеров из основного дерева задач, чтобы не загромождать рабочее пространство разработчика.


### 4. Политика срабатывания в группах Telegram (`mentionPolicy` / `freeChatGroups`)
- **По умолчанию**: `addressed` (реагирует только на @упоминания или прямые ответы).
- **Назначение**: Позволяет задать список групп, где бот отвечает на все сообщения без обязательного упоминания.

### 5. Сворачиваемый блок цепочки мыслей (`thinkingDisplay`)
- **По умолчанию**: Отключено (`off`)
- **Назначение**: Передает процесс рассуждений модели в Telegram в виде сворачиваемой цитаты (`<blockquote expandable>`).

## Использование и команды

Откройте **Настройки → IM-ассистент**, выберите **Добавить аккаунт** и укажите рабочую область, модель, права и режим отправки.

| Задача | Действие | Примечания |
| --- | --- | --- |
| Добавить аккаунт | Нажмите **Добавить аккаунт** под нужным каналом | Разрешено несколько аккаунтов на канал |
| Изменить настройки | Нажмите «Настройки» в строке аккаунта | Применяется мгновенно |
| Приостановить прием | Отключите переключатель **Принимать сообщения** | Учетные данные сохраняются |
| Новая сессия | Отправьте `/new` или `/clear` | Создает чистую сессию в канале |
| Статус / Справка | Отправьте `/status` или `/help` | Выводит текущую сессию и команды |
| Пресеты агента | `/presets`, `/preset <номер/ID>` | Переключает рабочий профиль агента |
| Модель и размышления | `/models`, `/model <имя>`, `/reasoning [уровень]` | Динамически настраивает модель |
| Управление сессиями | `/sessions`, `/session <номер/ID>`, `/rename <имя>`, `/fork` | Список, смена, переименование или ветвление сессий |
| Повтор отправки | `/delivery`, `/delivery retry <ID>` | Повторно отправляет прерванные сообщения |

### Автоматическое именование тем в Telegram

Темы форумов в Telegram именуются автоматически по первому ответу ассистента. Синхронизировать название вручную можно командой `/rename <заголовок>`.

### Сегментированные ответы

Позволяет разбивать длинные ответы на несколько коротких сообщений для удобного чтения на экране телефона (активно в QQ).

### Ротация сессий по неактивности

Если с момента последнего сообщения прошло заданное время (например, 1 час, 6 часов), следующее сообщение автоматически начнет новую сессию.

### Подключение Slack

1. Создайте приложение на портале Slack API (`api.slack.com/apps`).
2. В **OAuth & Permissions → Bot Token Scopes** предоставьте права для сообщений, файлов, реакций и упоминаний.
3. Установите приложение в рабочую область и скопируйте Bot Token (`xoxb-`).
4. Включите **Socket Mode** и создайте App-Level Token (`xapp-`).
5. Укажите оба токена в DSH для безопасного подключения по WebSocket.

## Безопасность и разграничение прав

- **API управления**: Развернуто на `/api/dsh-im-connect` с аутентификацией сессий DSH.
- **Хранение секретов**: Токены надежно изолированы во встроенных хранилищах хоста.
- **Одобрение инструментов**: Авторизуйте действия прямо в чате без перехода в браузер.
